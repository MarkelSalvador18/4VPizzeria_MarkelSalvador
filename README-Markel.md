# 4VPizzeria
Aplicación web desarrollada en Angular para gestionar un catálogo de pizzas añadir productos al pedido y finalizar la compra mediante un formulario.

## Tecnologías utilizadas
    -Angular 22
    -TypeScript
    -Bootstrap 5
    -Componentes

## Funcionalidades principales

### ✔ Listado de pizzas  
Página donde se muestran todas las pizzas disponibles.  
Permite filtrar pizzas mediante ingredientes en el buscador de el navbar.

### ✔ Sistema de pedido  
El usuario puede añadir pizzas al pedido.  
El pedido se gestiona mediante signals.

### ✔ Formulario de compra  
Incluye validaciones en tiempo real:
    -Dirección
    -Hora
    -Método de pago(Bizum o Tarjeta)

### Gestón del estado
El pedido se limpia una vez pulsado el boton de pedir
